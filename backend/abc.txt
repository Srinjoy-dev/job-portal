--If withCredentials is false (or you don't include it), the browser won't send cookies with a cross-origin Axios request.

In your project, the important cookie is the JWT authentication cookie.

So:

Login:

Backend gives browser a JWT cookie 🍪
Browser stores it

Later request with withCredentials: true:

Browser sends that cookie → backend knows which user is logged in

Later request without withCredentials: true:

Cookie isn't sent → backend doesn't receive the JWT
Authentication middleware can't verify you
The request will usually be rejected as not authenticated.

So you can think of withCredentials: true as:

"Include my login cookie when talking to the backend."

---Redux is basically a central storage place for data that many different React components need to access.

Without Redux:
Navbar → has some user data
Profile → has some user data
Jobs → needs some user data
You might have to pass that data around between components, which can get messy.
Redux is like a shared cupboard in your application. Instead of every component keeping its own copy of 
important information, they can all go to the same cupboard to get or update it.
